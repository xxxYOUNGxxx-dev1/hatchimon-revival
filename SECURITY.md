# Security

Do not post keys, access tokens, unredacted bugreports, or private save files in public issues. Redact personal identifiers from ADB output.

The release includes legacy game and advertising components plus an experimental translation runtime. This project documents compatibility fixes; it does not claim a complete security audit of those components.

For a sensitive finding, use a private contact route on the maintainer's GitHub profile if available. Publish a redacted report only after sensitive material has been removed.
