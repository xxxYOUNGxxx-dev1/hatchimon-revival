# Changelog

## 1.13-dev5 — first public revival release

- Package the original 1.13 ARM32 engine in an ARM64 ZettaBridge 0.1.0 host.
- Add a farm developer menu with billion-unit currency grants, safe balance caps, ranks 1–72, monster types, and batch spawning.
- Preserve the game's existing glowing rank 37–72 sprite behavior.
- Fix denied telephony access in legacy Unity/Google Ads code and Android 13+ Vungle receiver registration.
- Repair repeated-build launcher manifest duplication.
- Verify launch, progression, extended ranks, battles, resume, and save persistence on an Android 16 ARM64-only phone.
- Publish source additions, build tooling, validation evidence, English documentation, and a Russian introduction.

Earlier Dev2–Dev4 builds were local development iterations, not public releases.
